AI Chatbot 🤖

AI Chatbot is a Deep Learning-based conversational chatbot developed using PyTorch. The chatbot is trained on predefined intents and responses to interact with users and answer queries intelligently.

🛠️ Tech Stack
- Python
- PyTorch
- NLP
- NumPy
- NLTK


📌 Features
- AI-powered chatbot
- Intent-based response system
- Natural Language Processing (NLP)
- Deep Learning model using PyTorch
- Interactive conversation support
- Custom training data support


▶️ Run the Chatbot:- 
- python chat.py

The chatbot will start interacting through the terminal.
